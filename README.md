# Deployment

This app uses app-based release channels; it automatically deploys to the Preview environment with every merge to `main`. Deployments to the live site (prod) are deliberately manual.

# Preview environment

Since this app has seasonal features, the purpose of the Preview environment is to allow admins to have a sort of "live sandbox" that also has an environment-specific datepicker to conveniently verify seasonal features.
